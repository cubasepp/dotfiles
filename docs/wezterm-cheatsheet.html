Spawn vs. attach vs. detach

Persistence is real, but it is attach that uses it. A new tab always starts a fresh shell in $HOME — that is tmux new-window, not tmux attach. If the Pi looks like it never remembers a directory, that is why.

Detach (⌘⇧U) hands panes back to the mux server; close (⌘W) or exit reaps them. Nothing survives a reap, so an empty server is indistinguishable from a cold start.

ssh raspberry wezterm cli list   # what is still alive

Why the CLI blocks

wezterm connect rasperry     # blocks the shell
wezterm connect rasperry &!  # detached (zsh)
wzc                          # same, as a function

wezterm connect is a foreground client: it lives as long as its window. Not a hang.

Mux multiplexing is on

No multiplexing field set, so it defaults to "WezTerm": a wezterm-mux-server runs on the Pi and keeps your tabs alive after you disconnect, tmux-style.

Both sides are on 20240203-110809 — matching versions, which the mux protocol requires.

Every client attaches to the same session, so a tab opened on the laptop shows up here too. Want plain SSH instead? Add multiplexing = "None".

The domain picker is hand-rolled. WezTerm always synthesizes a local mux domain named unix (~/.local/share/wezterm/sock) whether or not unix_domains is configured, and the stock ShowLauncherArgs{flags="DOMAINS"} launcher offers no way to hide a domain. Attaching that one is the local mux domain this setup deliberately dropped — it mis-draws partial repaints (fzf in --height mode, stuck alt screens). So ⌘⇧O is an InputSelector listing only local and the Pi. See domains.lua.

The loop: ⌃⇧X → move to the start → v → move to the end → y. Use it to grab something that has scrolled past — an error, a SHA, a path — without reaching for the mouse or fighting a TUI that captures clicks. Unlike QuickSelect it is manual and precise, and reaches the entire scrollback.

Tab bar internals

Two Lua event handlers do the work: format-tab-title (icons, colors, truncation) and update-status (workspace badge, cwd, battery, clock).

use_fancy_tab_bar = false is what allows real powerline separators. The status line renders inside the tab bar — so hiding the bar hides the status line too.

The macOS fix

why ⌃⇧Space was dead

The key never reached WezTerm. macOS’s input-source switcher claims ⌃Space and an undocumented ⌃⇧Space for cycling backwards — the latter appears nowhere in System Settings. No amount of Lua could have fixed it.

Disabled

60⌃Spaceprev input source
61⌃⌥Spacenext input source

in com.apple.symbolichotkeys

To undo

System Settings → Keyboard → Keyboard Shortcuts → Input Sources, re-check the boxes. Or:

cp ~/symbolichotkeys.plist.bak \
   ~/Library/Preferences/com.apple.symbolichotkeys.plist

Untouched: ⌘Space (Spotlight) and ⌃⌘Space (emoji). You lose keyboard input-source switching — irrelevant with only the ABC layout installed.
